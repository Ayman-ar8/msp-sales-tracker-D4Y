# How to fill in your EOD report

One report at the end of every working day. It takes about two minutes.
All numbers are **for that day only**.

## Closers

| Question | What to put |
|---|---|
| Date | The day the report is for (not the day you send it, if late) |
| Did you work today? | "Day off" skips the rest |
| Calls on your calendar | Every call booked on your calendar today, new and follow-up |
| Shows: new calls | First calls with a prospect that happened |
| Shows: follow-up calls | Second or later calls that happened |
| No-shows | Booked, didn't turn up |
| Reschedules / Cancelled | Moved to another day / cancelled |
| Disqualified | Showed but not a fit |
| Offers made | Prospects you pitched |
| Closes: paid in full | Deals closed today, paid in full |
| Closes: payment plan | Deals closed today on a payment plan |
| Deposits taken | Deposits taken today where the balance isn't closed yet |
| Contract value closed | Total value of today's paid-in-full and payment-plan closes |
| Cash: upfront | Cash from today's paid-in-full deals |
| Cash: payment plan | First payments from today's plan deals **plus any instalments you collected today** |
| Cash: deposits | Deposit money taken today |

### Deposits: the one rule to remember

**A deposit is not a close.** Log it under "Deposits taken" and "Cash:
deposits". When the balance is closed later, log that day as a
paid-in-full or payment-plan close, with that day's cash. The deposit cash
you logged earlier stays under deposits, so nothing is counted twice.

## Setters

| Question | What to put |
|---|---|
| Conversations | Prospects you spoke with today |
| Qualified conversations | Of those, how many were a fit |
| Calls booked | Calls you booked today (for any future date) |

## Mistakes and late reports

- **Made a mistake?** Submit again for the same date. The latest one counts.
- **Forgot yesterday?** Submit it now with yesterday's date.
- **Numbers only**: no currency signs or commas. Put 0, not blank.
